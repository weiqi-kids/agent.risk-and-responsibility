## L1 — Rule Signal
- **rule_type**: guidance

## L2 — Responsibility Structure
- **affected_roles**: CISO、AI 安全工程師、雲端架構師、DevOps 工程師
- **shift_type**: new
- **shift_summary**: MCP（Model Context Protocol）成為自主 AI Agent 控制平面後，CISOs 需在 MCP 驅動自動化進入生產前建立治理、可見性與防護措施

## L3 — Risk Domains
- AI 安全（MCP 新型攻擊面）
- 雲端安全（開發管道與營運系統風險）
- AI 治理（自主 AI Agent 治理缺口）

## L4 — Obligation & Evidence
- **new_obligations**:
  - 建立 MCP 治理框架，涵蓋 Agent 權限管控
  - 識別並緩解內容注入攻擊（content-injection attacks）
  - 限制 AI Agent 過度權限（over-privileged agents）
  - 建立供應鏈風險管控機制
- **evidence_requirements**:
  - MCP 使用資產清單與授權記錄
  - Agent 權限最小化設定文件
- **enforcement_signal**: recommended
