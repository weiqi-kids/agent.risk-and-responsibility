## 競品詳細分析

### 競品 A：NIST CSRC

#### 基本資訊

| 項目 | 數據 |
|------|------|
| URL | https://csrc.nist.gov/ |
| 定位 | 美國國家標準暨技術研究院的資安資源中心，發布框架、指南、標準 |
| 目標受眾 | 聯邦機構、政府承包商、全球資安從業者 |

#### 內容策略

| 項目 | 觀察 |
|------|------|
| 資訊架構 | 依出版物類型分類（SP 800 系列、FIPS、NISTIR）+ 主題分類（Cybersecurity、Privacy、AI RMF） |
| 主要內容類型 | 正式出版物（PDF）、公開徵求意見稿、新聞公告、活動/研討會 |
| 更新頻率 | 不定期，依出版物發布節奏；新聞公告約每週 1-3 則 |
| 特色內容 | CSF 2.0 Reference Tool、Privacy Framework、AI RMF Playbook |

#### 優勢與特色

1. **最高權威性**：政府機構官方來源，E-E-A-T 無可挑戰
2. **內容深度極佳**：每份出版物數十至數百頁的完整技術文件
3. **結構化參考工具**：CSF 2.0 提供互動式瀏覽和 JSON/Excel 匯出
4. **免費且公開**：所有出版物皆可免費下載

#### 可改善之處

1. **導航複雜**：出版物編號系統（SP 800-53 Rev. 5）對非專業人員不直觀
2. **缺乏跨框架整合**：各出版物獨立呈現，未提供跨框架交叉分析
3. **無週期性摘要**：沒有「本週有什麼新變動」的彙整報告
4. **搜尋體驗普通**：全文搜尋結果的相關性排序不夠精準

### 競品 B：EUR-Lex

#### 基本資訊

| 項目 | 數據 |
|------|------|
| URL | https://eur-lex.europa.eu/ |
| 定位 | 歐盟法律的官方公報資料庫 |
| 目標受眾 | 法律專業人員、政策制定者、歐盟成員國合規部門 |

#### 內容策略

| 項目 | 觀察 |
|------|------|
| 資訊架構 | 依法律類型分類（Regulation、Directive、Decision）+ 依主題領域（ECLI 法規分類） |
| 主要內容類型 | 法律全文、立法程序追蹤、案例法、國家轉置措施 |
| 更新頻率 | 即時（OJ 公報發布即上線） |
| 特色內容 | 法規合併版本（consolidated text）、立法程序追蹤（procedure viewer） |

#### 優勢與特色

1. **法規原始來源**：歐盟法律的唯一官方資料庫
2. **多語言**：24 種歐盟官方語言
3. **立法追蹤**：可追蹤法案從提案到通過的完整歷程
4. **合併版本**：自動產出含所有修正案的合併法規全文
5. **開放資料**：提供 SPARQL 端點和 CELLAR 資料集

#### 可改善之處

1. **法律專業門檻高**：非法律背景使用者難以理解法規含義
2. **無影響分析**：僅呈現法規文本，不分析對特定產業/角色的影響
3. **缺乏行動指引**：告訴你「規定了什麼」，不告訴你「該做什麼」
4. **介面設計老舊**：搜尋和瀏覽體驗有改善空間

### 競品 C：MITRE ATT&CK

#### 基本資訊

| 項目 | 數據 |
|------|------|
| URL | https://attack.mitre.org/ |
| 定位 | 全球性的攻擊者戰術、技術和程序（TTP）知識庫 |
| 目標受眾 | SOC 分析師、紅隊/藍隊、威脅情報分析師、資安架構師 |

#### 內容策略

| 項目 | 觀察 |
|------|------|
| 資訊架構 | 矩陣式呈現（戰術 × 技術）+ 群組/軟體/緩解措施的交叉引用 |
| 主要內容類型 | 技術描述、偵測建議、緩解措施、威脅群組側寫 |
| 更新頻率 | 版本制（約每半年一次大版本，穿插小更新） |
| 特色內容 | ATT&CK Navigator（互動式矩陣工具）、STIX/TAXII 資料格式 |

#### 優勢與特色

1. **業界標準地位**：已成為威脅情報的共通語言和分類框架
2. **開源且結構化**：GitHub 上提供 STIX 格式的完整資料集
3. **社群生態系統**：大量第三方工具整合（SIEM、SOAR、紅隊工具）
4. **視覺化工具**：ATT&CK Navigator 可互動式瀏覽和標記
5. **跨平台覆蓋**：Enterprise、Mobile、ICS 三大矩陣

#### 可改善之處

1. **偏技術攻擊面**：不涵蓋法規合規、責任歸屬等治理面向
2. **更新週期較長**：半年一次大版本，對快速變動的威脅環境偏慢
3. **學習曲線陡峭**：矩陣龐大，新手不易找到切入點
4. **無法規關聯**：不連結到具體的合規要求或責任義務

## 關鍵發現

### 1. 差距（他們有我們沒有）

| 項目 | 競品 | 影響 | 建議 | 優先級 |
|------|------|------|------|--------|
| 人工審核/專家背書 | 所有競品 | E-E-A-T 可信度不足——本站為 YMYL 類內容卻無人工審核標記，是 Google 排名和使用者信任的最大風險 | 加入「Reviewed by [Name]」區塊；在 About 頁面呈現審核者資歷和方法論 | **P0** |
| 互動式工具 | NIST CSF Tool、MITRE Navigator、AI Act Checker | 使用者參與度低——靜態報告缺乏互動，用戶無法依自身情境篩選和探索 | 短期：加入依角色/議題的篩選導航；中期：開發簡易合規自評問卷 | **P1** |
| 即時性/高頻更新 | Thomson Reuters（即時）、EUR-Lex（即時）、AI Act 站（即時） | 週報週期意味著 1-7 天的資訊延遲——對急迫性法規變動（如生效日期逼近的實施細則），使用者仍需回到原始來源 | 明確定位為「週度彙整分析」而非「即時警報」；在報告中標註資料時間範圍 | **P1** |
| 可下載資源 | UpGuard（模板）、NIST（PDF） | 缺少可離線使用的資源格式，無法支援「列印給主管看」或「帶進會議」的場景 | 提供 PDF 版週報下載；考慮 Excel 格式的法規追蹤表 | **P2** |
| 多語言支援 | EUR-Lex（24 語言）、AI Act 站（Weglot） | 目前僅中/英文，限制國際受眾覆蓋；部分報告以繁體中文撰寫，可能影響英語系受眾體驗 | 確保核心報告有完整英文版；長期考慮日文/韓文版 | **P2** |
| 合規管理工作流 | Thomson Reuters | 本站僅提供「資訊」而非「工具」，無法追蹤合規任務的分派和完成狀態 | 超出目前定位範圍；可在報告中加入「建議行動清單」作為輕量替代 | **P2** |

### 2. 優勢（我們有他們沒有）

| 項目 | 說明 | 如何強化 |
|------|------|----------|
| **跨框架整合分析** | 唯一將 NIST + EU + ISO + CISA + CSA + SANS 整合為統一分析的免費來源；Thomson Reuters 有類似能力但年費 $10K+ | 在首頁和每份報告中強調「7 來源整合」的獨特價值；加入跨來源交叉引用（如「此 NIST 更新與 EU AI Act 第 X 條相關」） |
| **責任歸屬結構化追蹤** | `shift_type` + `affected_roles` + `shift_summary` 的分類法在所有競品中未見；即使 Thomson Reuters 也僅提供法規文本分析，不追蹤「責任如何從 A 轉移到 B」 | 獨立出「責任追蹤」專頁，以視覺化方式呈現責任轉移趨勢；強化 SEO 佈局搶佔 "responsibility attribution framework" 關鍵字 |
| **開源透明的萃取邏輯** | 萃取規則、報告產出流程完全公開——使用者可檢視、審計、甚至 fork 建構自有系統；商業競品全為黑箱 | 在 About 頁面加入「方法論」區塊，連結到 GitHub 上的萃取邏輯；強調「可審計性」作為信任元素 |
| **自動化週報機制** | 系統性地每週產出 7 份報告——權威來源（NIST、EUR-Lex）不做彙整，專注站（AI Act）不做跨源整合，內容行銷（UpGuard）不做定期更新 | 確保 7/7 Mode 每週準時產出（目前 5/7）；加入「連續產出週數」作為信譽指標 |
| **免費且無付費牆** | 與 Thomson Reuters（$10K-$100K+）形成最大差異；比 UpGuard 更中立（不引導購買產品） | 在品牌訊息中明確對比：「商業法規追蹤服務年費六位數，我們完全免費」 |
| **向量語意搜尋** | 基於 Qdrant + text-embedding-3-small 的語意搜尋，851+ 份文件可被自然語言查詢——NIST/EUR-Lex 僅有關鍵字搜尋 | 開放搜尋介面給使用者（目前僅系統內部使用）；長期提供 API 端點 |

### 3. 機會（可以做得更好）

## 差異化建議

基於競品分析，建議以下差異化策略：

### 1. 強化「開源合規整合」的獨特定位

本站佔據的生態位是：**免費、開源、跨框架、結構化的合規情報彙整**。這個定位在競品光譜中是獨一無二的——權威來源（NIST/EUR-Lex）不做整合，MITRE 不涵蓋治理，Thomson Reuters 收費高昂且封閉，垂直站（AI Act）範圍太窄，內容行銷（UpGuard）偏商業導向。

**行動**：在所有接觸點（首頁、About、報告標頭）一致傳達「7 來源 × 7 報告 × 完全開源」的核心訊息。

### 2. 補齊 E-E-A-T 短板

這是目前最大的競爭劣勢。所有競品都有某種形式的人工專家參與，本站是唯一純 AI 產出的來源。在 YMYL（Your Money or Your Life）類內容領域，Google 對 E-E-A-T 信號的要求尤其嚴格。

**行動**：
- P0：加入人工審核者資訊（即使是「抽樣審核」也比「無審核」好）
- P0：強化免責聲明和方法論說明的可見度
- P1：在 About 頁面建立完整的「我們如何運作」流程說明

### 3. 深耕「責任歸屬追蹤」獨特賣點

`shift_type` + `affected_roles` 的分類法是所有競品中未見的。這不只是功能差異，更是思維框架的差異——從「法規說了什麼」轉向「責任如何轉移」。

**行動**：
- 獨立出「Responsibility Tracker」專題頁面
- 產出「2026 責任歸屬變動年度報告」作為 SEO 內容資產
- 針對 "responsibility attribution framework" 優化 SEO

### 4. 以「自動化週報」建立習慣黏性

Thomson Reuters 靠即時性取勝，但使用者為此付出高昂費用和認知負荷。本站的「每週一份彙整」反而是優勢——降低資訊過載，適合「週一早上花 15 分鐘掌握全貌」的使用場景。

**行動**：
- 確保 7/7 Mode 每週準時產出（目前 5/7）
- 實作 RSS/email 訂閱，在每週一早上推送
- 在報告中加入「本週閱讀時間：約 X 分鐘」的標記
